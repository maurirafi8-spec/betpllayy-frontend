# BetPllayy V8.0 FINAL ARENA

12 jogos arcade e três modos em todos eles:
- Solo
- VS CPU
- PVP por sala/código

PVP é por rodada de placar: os dois jogadores jogam o mesmo desafio no próprio celular e o backend compara os resultados.

Novos jogos: Pong Arena, Air Hockey, Pênalti Pro, Dardos 301, Basket Shot e Memory Duel.
Sinuca Pro V7.5 foi preservada.
